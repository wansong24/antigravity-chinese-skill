   Google Antigravity 全生态中文汉化套件 (Windows 专享版 v4.0.0)
   特性：客户端全中文界面 + 原版思考过程(零降智) + 100% 简体中文输出
====================================================================

【一、前置条件（必看）】
电脑需已安装 Node.js（版本 >= 16.0.0）。
- 检查方法：按 Win + R 输入 cmd 回车，输入 node -v 看是否有版本号。
- 如未安装：请打开 https://nodejs.org 下载左侧 LTS 版本默认安装即可。

--------------------------------------------------------------------
【二、按顺序双击使用说明】

1. 【1-双击安装或更新中文汉化.bat】（日常首选）
   - 作用：一键汉化 Windows 桌面版 Antigravity 客户端界面、VS Code 扩展，
           并自动安装「原版思考 + 100% 中文输出」全局规则插件與 Skill。
   - 操作：建议先关闭正在运行的 Antigravity 客户端（或在弹窗提示输入 y 时
           按 y 回车由脚本自动安全关闭），等待提示「汉化补丁安装成功」即可。
   - 后续如果 Antigravity 自动升级变回了英文，再次双击此 1 号脚本即可恢复。

2. 【2-双击检查汉化状态.bat】
   - 作用：随时检查当前客户端路径、安全备份、UI 汉化状态及全局中文插件状态。

3. 【3-双击自愈启动Antigravity.bat】
   - 作用：可将该脚本发送快捷方式到桌面。每次双击它启动 Antigravity 时，若
           检测到官方更新覆盖了汉化，会自动重打补丁后再启动软件。

4. 【4-双击卸载还原官方英文.bat】
   - 作用：一键从安全备份 app.asar.bak 恢复官方纯净英文原版，并移除中文插件。

--------------------------------------------------------------------
【三、全局中文规则插件安装位置（自动配置，无需手动干预）】
安装后自动写入：%USERPROFILE%\.gemini\config\plugins\chinese-toolkit
- 内部推理（Thinking）：100% 保持模型原版自然状态，不被词典生硬替换；
- 正式回复、计划、报告与工具状态提示：100% 锁定使用简体中文。
